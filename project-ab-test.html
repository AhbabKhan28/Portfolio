A/B Test Analysis

Does a new landing page actually convert better? A full frequentist analysis that turns an experiment into a confident, data-driven ship decision.

PythonNumPySciPyHypothesis TestingStatistics

Overview

Two groups of 12,000 users each — control (old page) and treatment (new page) — are compared on conversion rate. The analysis doesn't just report which number is bigger; it quantifies whether the difference is statistically significant and how large the true effect is likely to be.

Key Results

12.18%Control conversion
13.29%Treatment conversion
+9.1%Relative lift
p = 0.010Significant at α=0.05

Approach

  • Simulate a two-group experiment from a known ground truth (reproducible seed).
  • Two-proportion z-test using a pooled standard error to compute the z-statistic and p-value.
  • 95% confidence interval for the difference in conversion rates (unpooled SE).
  • Decision rule: reject H₀ when p < 0.05 → the lift is real and the CI excludes zero, so it's safe to ship.
z = (p_t - p_c) / sqrt( p_pool * (1 - p_pool) * (1/n_c + 1/n_t) )
p_value = 2 * (1 - Φ(|z|))  # two-sided

Tech Used

  • Python — NumPy for simulation, SciPy for the normal distribution
  • Statistics — two-proportion z-test, confidence intervals, significance testing
  • matplotlib — conversion comparison chart
