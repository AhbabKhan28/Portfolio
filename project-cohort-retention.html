Data Analysis Project

Marketing Cohort Retention

How sticky is the product, and is it getting stickier? A monthly cohort retention analysis computed two independent ways — pandas and SQL — as a built-in cross-check.

PythonpandasSQLSQLiteCohort Analysis

Overview

8,000 users are grouped by their signup month (cohort), then tracked to see what fraction return in each following month. The result is a retention matrix — cohorts down the side, months-since-signup across the top — visualized as a heatmap.

Key Results

~54%Avg month-1 retention
~36%Avg month-3 retention
8,000Users tracked
12Monthly cohorts

Approach

  • Event log: simulate signups + monthly return activity with geometric decay and a small cohort-quality trend.
  • Python: compute months-since-signup per event, divide active users by each cohort's month-0 size, and render a heatmap.
  • SQL: reproduce the exact same matrix using date arithmetic on YYYY-MM strings and COUNT(DISTINCT user_id).
  • Cross-check: the pandas and SQL matrices match cell-for-cell — a reliability check on the logic.
retention[cohort][k] = active_users(cohort, month k) / cohort_size(cohort) * 100

Tech Used

  • Python — pandas period arithmetic, matplotlib heatmap
  • SQL — SQLite CTEs, date math, distinct counts
