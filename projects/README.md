# Data Analytics Projects

Hands-on data-analyst projects showcasing **Python**, **SQL**, and **Power BI**.
All datasets are synthetic and generated locally (reproducible seeds) so every
project runs end-to-end with no external downloads.

| # | Project | Stack | Highlights |
|---|---------|-------|-----------|
| 1 | [Retail Sales Analytics](retail-sales-analytics/) | Python, SQL, Power BI | Star-schema EDA, 6 SQL business queries, DAX dashboard guide |
| 2 | [A/B Test Analysis](ab-test-analysis/) | Python (scipy) | Two-proportion z-test, confidence interval, ship decision |
| 3 | [Marketing Cohort Retention](cohort-retention/) | Python, SQL | Cohort retention matrix + heatmap, computed in Python *and* SQL |

## Setup
```bash
pip install -r projects/requirements.txt
```
Then follow the README in each project folder.
